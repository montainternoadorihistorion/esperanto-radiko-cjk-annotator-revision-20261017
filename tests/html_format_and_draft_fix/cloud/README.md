## 証拠の読み方

`ui_observations.json` は画面操作による18順変換・24HTML復元の確認記録。`validation.json` は保存ファイルの独立照合であり、両者を合わせて読む。最初のHTML復元2行にfile項目がないが、対応する実ファイルは独立照合に含まれる。

`validation.json` の `expected_source_commit=ce19f04...` は、未コミットの修正ソースで期待値を作成した時点の親HEADであり、実行したソースが旧版だったという意味ではない。期待値生成時に記録した15ソースのSHA256は最終配備ソースと一致することを独立確認した。順変換の保存コメントは生成時刻だけが可変で、版・署名・本文は厳密に照合した。

平文逆変換では、保護して出力した漢字 `放` も通常の辞書で逆引きされ、新版では `las`、旧版では `emancip` になる。消費した@・%の目印を含めた入力そのものの完全復元を主張しない。HTML復元では保護内容と空白を維持できる。

編集済みHTML・自作JSONの追加保存2件は46件の独立照合集計とは別で、画面操作時に本文・形式情報の有無・復元結果を確認した。形式情報のない旧HTMLの互換性はローカル40比較でも確認済み。旧ファイルの形式を推測して自動判別する機能は追加していない。
