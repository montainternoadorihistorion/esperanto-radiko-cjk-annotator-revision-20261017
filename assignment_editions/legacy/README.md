# 固定旧版の漢字割り当て

最初の `las` 割り当て変更前であるコミット
`4c16c8937c601fdc149ccb8cbba1b6085cc94692` の正本・識別子・漢字変換表を固定した版です。
今後更新する新版とは独立しています。

- 正本10,467語根と識別子をそのまま保存しています。
- 通常変換と2文字規則は当時の全行を維持しています。
- 当時の `@` データに残っていた確認済み10語根の旧値だけを、同じ当時の正本に合わせています。手動補正用CSVも同じ10語根だけ同期しています。
- 42件の既存分解と9件の同綴別義の選択は変更していません。
- 新しい漢字割り当て、後日の成分識別子統一、追加語根 `prioritat` と `spermatozo` は取り込んでいません。
- 注釈と変換機構の不具合修正は現行アプリと共用します。そのため、当時のアプリの不具合を含む完全な再現版ではありません。

`manifest.json` に原データと収録データのSHA256、基準コミット、限定した修正内容を記録しています。
大きいJSONは再現可能なgzip（mtime=0）で収録しています。原辞書・日記・アカウント情報は含みません。

旧逆変換辞書に元から含まれない4語根（`endoskopi`、`mikroskopi`、`asistoli`、`eu^foni`）など、
既存の制約まで解消したという意味ではありません。過去文書の完全な自動復元を保証するものではありません。

固定データを確認するには、リポジトリのルートで次を実行します。

```text
python -B -X utf8 assignment_editions/legacy/test_legacy_assets.py
```

検査は固定manifest自体のSHAも照合するため、新版の更新に伴って旧版を上書きすると停止します。
