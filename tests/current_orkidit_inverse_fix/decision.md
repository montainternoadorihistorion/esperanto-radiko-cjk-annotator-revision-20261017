# 新版の orkidit 系通常表記に対する復元補助（2026-10-18）

ユーザーは、旧版で解消した復元不一致に続いて、新版の語尾なし・形容詞・動詞などに残る不一致も修正するよう明示した。漢字割り当て、既存の正しい語根分解、識別子を維持し、新旧の通常・@・逆変換を検証してStreamlit Cloudに反映する。

## 原因と採用方法

新版の通常変換では `orkidit → 兰炎ᵀ`、`orkidita → 兰炎ᵀa`、`orkiditi → 兰炎ᵀi` などの表示が存在する。新版逆変換辞書にはこの完全表記がないため、部分一致で `orkidkatarᵀ` を含む形へ復元される。Cloudの日本語・中国語両版でも修正前に再現し、`cloud_before.json` に実入力・実出力を保存した。

新版の逆変換実効辞書だけに、完全表記 `兰炎ᵀ → orkidit` を補う。漢字割り当ての代表表記を `兰炎ᵀ` に変更するものではない。通常変換・@変換の規則、語根の区切り、注釈、正本CSV、元の配布CSVは変更しない。`兰` や `炎ᵀ` 単体の対応を変更せず、既存の最長一致処理を使用する。

旧版の復元補助3件とその改訂・ハッシュ・配布内容は維持する。途中版および独自CSVへ新版用補助を自動適用しない。通常画面の版選択は新版・旧版の二つのままにする。

## 配布と今後の見直し

新版の画面には、補助対応を含む実効逆変換CSVも提供する。元のCSVはそのまま保存し、アプリと同じ結果を再現したい場合は補助込みCSVを使用できるようにする。変換結果の版表示とファイル名には補助対応の改訂・ハッシュを含め、修正前の結果は再変換してからダウンロードする。

今後漢字割り当てを更新する際には、補助対応の衝突、既存語根の復元、通常・@変換との整合性を再検証する。補助対応が古いまま新しい辞書へ誤適用されないよう、適用先の辞書と対応表を検査する。

## 検証方針

変更前の実効辞書を基準にする（旧版の復元補助は既に適用済み）。既存全キーの復元結果、日中韓・新旧・全3モードの順変換出力と元データ、対象語の語尾なし・活用形・派生形・通常および@経路を比較する。Cloudでは順変換の実出力を逆変換へ渡し、画面、実ダウンロード、版情報、補助込みCSVの再アップロード、版切替保護を確認する。

HTMLソースのタグ除去や元の大文字の復元、任意の曖昧な複合語まで解決したとは扱わない。以前の検証記録は当時の観測として保存し、今回の解消結果を別の記録に残す。
