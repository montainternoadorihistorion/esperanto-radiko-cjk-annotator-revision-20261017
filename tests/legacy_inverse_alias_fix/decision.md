# 固定旧版の通常表記を復元する補助対応（2026-10-18）

ユーザーは、固定旧版の漢字割り当てを変えずに `testikito`・`orkidito` の復元不一致を修正し、新旧の通常変換・`@` 変換・逆変換と識別子を検証したうえでCloudへ反映することを明示承認した。

## 原因と対象

固定旧版の通常変換は `testikito → 丸ᵀ炎ᵀo`、`orkidito → 丸ᴼ炎ᵀo` を出力する。一方、固定旧逆変換辞書の対応は `testikit＝丸炎ᵀ`、`orkidit＝丸炎` であり、通常表記の完全なキーが存在しない。このため部分一致で `testikkatarᵀo`・`orkidkatarᵀo` となっていた。

旧版で語尾なしの `orkidit` を通常変換すると `兰炎ᵀ` となる経路も確認されている。同じ語根の復元漏れとして、この完全表記も対象に含める。

| 固定旧版から出る表記 | 復元先 |
|---|---|
| 丸ᵀ炎ᵀ | testikit |
| 丸ᴼ炎ᵀ | orkidit |
| 兰炎ᵀ | orkidit |

## 採用する方法

固定旧CSV、漢字正本、識別子表、順変換データは変更しない。旧版を明示選択した場合だけ、逆変換の実効辞書へ上の3対応を追加する。汎用の `炎ᵀ` 置換や識別子の除去は行わず、既存の最長一致処理を使う。旧 `@` 表記の `丸炎ᵀ`・`丸炎` はそのまま保持する。

新旧の選択肢は2つのままとする。新版・途中版・独自CSVへ補助対応を自動で適用しない。元の固定CSVと2列CSVのダウンロードは従来の全バイトを維持する。別途、固定旧版の復元補助を含む逆変換用CSVを提供し、アプリと同じ復元内容を独自CSVでも再現できるようにする。

補助対応は漢字割り当ての変更とは区別し、変換結果の版情報・ファイル名には補助対応の改訂とハッシュも記録する。修正前に生成した結果を、再変換することなく修正後の結果としてダウンロードさせない。

## 検証の区別

旧版の正しい辞書キーからの出力はすべて維持し、今回追加した3表記だけを復元可能にする。順変換の変更前後一致と逆変換の改善を別々に検証する。漢字化時に情報が失われる一般的な複合語の曖昧さや大文字の復元まで解消したとは扱わない。
