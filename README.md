## 操作と確認例

1. メインページで注釈ルビ・漢字ルビ・純粋置換のいずれかを選びます。
2. エスペラント文を入力して変換します。自作JSONや手動補正JSONの読み込みも利用できます。
3. 結果はプレビュー、編集、ダウンロードできます。語根分解の手動補正とデータのダウンロードはサイドバーから開きます。

今回の修正を確認する入力例：

```text
@semajn@tagoj & %amiko% ŝakisto semajntagoj
```

「漢字化・純粋置換」の期待結果：

```text
周日oj & amiko 棋家o 周日oj
```

- `@...@` は囲んだ部分への局所的な変換を指定し、対応する目印は変換後に消えます。語の途中の `@semajn@tagoj` にも対応します。
- `%...%` は囲んだ部分を変換せずに残します。`%` の保護が優先するため、`%@amiko@%` は `@amiko@` として残ります。
- 空の `@@`、対応相手のない `@`、改行をまたぐ囲みは局所変換の指定として扱いません。
- 文脈のない `semajn` は `sem/a/j/n`（種に関する形容詞の複数対格）にもなり得るため、一律には週の語根へ置き換えません。週を明示する場合は `@semajn@` を使えます。`semajntagoj` 等の確認済みの語では、週の語根を保護しています。

## 構成語根の識別子の統一（2026-10-17）

語全体への漢字割り当てにも、構成語根の確定済み識別子を引き継ぐ方針を適用します。たとえば `testik＝丸ᵀ` と炎症の `it＝炎ᵀ` を組み合わせる `testikit` は `丸ᵀ炎ᵀ`、`orkid＝丸ᴼ` を使う `orkidit` は `丸ᴼ炎ᵀ` です。語根の区切りや語義はこの変更の対象ではありません。

正本の割り当て済み10,468語根を照合し、成分の識別子を反映する1,520語根と、同字グループの再計算によって識別子が追随する14語根、計1,534語根を更新しました。元から優先指定のある基本形13件は、その指定語根を維持しています。漢字の選び直しや未割り当て成分の解釈を必要とする141語根は別途分類し、今回の識別子修正では変更していません。

```text
入力: testikito @testikit@o orkidito @orkidit@o
純粋置換: 丸ᵀ炎ᵀo 丸ᵀ炎ᵀo 丸ᴼ炎ᵀo 丸ᴼ炎ᵀo
```

通常変換は既存の辞書にある分解を使い、`@...@` は既存の局所登録に従います。独立した語根の表が存在するという理由だけで、正しい分解を語全体の割り当てへ置き換えたり、未登録の語根を局所用データへ一括追加したりはしません。成分の連結表記と語全体の表記が別の綴りを表す場合は、逆変換で混同しないよう、語全体にも識別子が必要になります。

この衝突を防ぐ9組について、既存の識別子生成規則で語全体を区別しました。`tripanosom＝原兽ᵀ`、`deism＝神主义ᴰ`、`deist＝神家ᴰ` は従来の識別子を保持します。新しく生じる表記の衝突は0件です。

統合リポジトリの日本語・中国語の逆変換アプリには、今回の修正直前の辞書を選べる項目を追加しています。古い文章には、作成時点に合う辞書を選んでください。新旧表記の意味が競合する場合があるため、自動判定は行いません。

## 精子と精液の区別（2026-10-18）

本人の明示採用により、前節の保留を解除します。`spermatozo` と既存の `spermat` 系列には「精子」、`sperm／ĉur` には「精液」を使います。植物語を含む系列共通の漢字表記を採用し、`spermatofitoj` の「種子植物」、`spermati` の植物の不動性生殖細胞など、個別の意味は注釈で保ちます。

| 語根 | 旧表記 | 採用表記 |
|---|---|---|
| `spermat` | 精ˢ | 精子 |
| `spermati` | 精ˢᴵ | 精子ˢᴵ |
| `spermatozo` | 未割当 | 精子ˢᶻ |
| `spermatocit` | 精ˢ胞ᶜᴵ | 精子胞ᶜᴵ |
| `spermatofit` | 精ˢ植ᶠ | 精子植ᶠ |
| `spermatogenez` | 精ˢ源ᴳ | 精子源ᴳ |
| `silf` | 精ˢᴸ | 精ˢ |

採用理由は、生殖細胞とそれを含む液体を区別し、系列の表記をそろえることです。「精」「子」は既用字を共用します。「精」14画から「精子」17画への増加は、今回の意味の区別を優先した本人の選択として記録します。`sperm＝精液` と `ĉur＝精液ᶜ̂` は維持します。

上付き識別子は既存アルゴリズムによる実計算です。新規の `spermatozo` は既定の追加優先度で登録し、無印を特別に割り当てません。旧「精ˢ」は `spermat`、現行「精ˢ」は `silf` になるため、統合側の逆変換には変更前辞書を別の版として保持します。

注釈も文脈ごとに確認しました。一般の `sperm／ĉur` は精液、`spermicid` の `sperm` 成分は精子、`endo/sperm`・`peri/sperm` の成分は種子の意味を保ちます。`@spermatocit@` の `cit` が一般語義の「引用する」へ戻る問題は、この複合語の中だけ「細胞」に修正しました。`spermat/o/cit` と `spermat/o/genez` の区切りを維持し、手動で語根全体を指定した場合には、それぞれ「精母細胞」「精子形成」の注釈を用います。
